# Icon.svg Readme

## Basic Rules

-Icon names should be in lower case.
-Icon names shoud be singular.
-Names of icons with more than one words should be seperated by a hyphen.
-The order of the svg file should be in accending order by name.

# Add a new Icon to Provider

-   To add a new icon, we need to add the symbol to icons.svg file.
-   To generate the svg, run npm svgr from cmd
-   Once the svgr has generated the component, we need to add the icon id to IconType file in icons folder
-   The same id/name should be used in the Icons.stories also
